# Desafio-Trilhas-03
DESAFIO 3

📝 O que é o projeto?
Este projeto é um sistema simples de cadastro, login e formulário de inscrição, feito como parte de um desafio proposto. Ele simula um pequeno sistema onde o usuário pode criar uma conta, fazer login e preencher um formulário com dados pessoais e de interesse.

🚀 Como rodar localmente
Clone o repositório:
git clone https://github.com/seu-usuario/seu-repositorio.git

Abra o projeto em seu editor de código favorito (como o VS Code).
Dê duplo clique no arquivo index.html para abrir no navegador
ou use uma extensão como Live Server para testar com atualização automática.
Observação: o projeto roda 100% no navegador, não requer servidor backend.

🛠 Tecnologias utilizadas
HTML5 – Estruturação das páginas
CSS3 – Estilização das interfaces
JavaScript (puro) – Validação, armazenamento e interação com usuário
LocalStorage – Para salvar os dados no navegador

✨ Principais funcionalidades
Página de cadastro com validação de e-mail e data de nascimento
Página de login com verificação das credenciais salvas
Redirecionamento para a página de formulário
Validação de campos obrigatórios e CPF
Efeitos visuais e interatividade com hover nas opções
Mensagens de erro e sucesso via alertas
Armazenamento e comparação de dados usando localStorage
Estilo e layout simples, mas funcional

✅ Boas práticas aplicadas
Separação clara entre HTML, CSS e JS
Funções reutilizáveis para validação
Condições bem estruturadas (uso correto de if/else)
Código comentado e organizado
Histórico de commits limpo e sem arquivos desnecessários
